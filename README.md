# Araújo Store — Vitrine Digital

Protótipo da **WS Desenvolvimento** para apresentação comercial à Araújo Store.

## Recursos da demonstração
- Catálogo de calçados, categorias e preços
- Seleção de numerações em caixas, exibindo apenas tamanhos disponíveis
- Cadastro de produtos e estoque demonstrativo
- Sacola e contato por WhatsApp
- Estatísticas demonstrativas de interação

## Estado do projeto
**Demonstração, não pronta para uso comercial.** O armazenamento local não sincroniza dados entre dispositivos. Para produção, implementar autenticação administrativa, banco de dados compartilhado, regras de acesso, backups e métricas centralizadas.

Confirmar com o proprietário autorização para uso das fotos e marca, preços atuais e telefone comercial antes da publicação.

## Publicação
Repositório privado inicialmente. O arquivo HTML demonstrativo ainda precisa ser adicionado como `index.html` antes de preparar a hospedagem.
